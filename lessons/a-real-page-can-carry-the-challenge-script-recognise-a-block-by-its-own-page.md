Recognise a challenge or block page by the block page's own landmarks (its title, its error block), never by the challenge script's name: real pages from a protected site carry that script too.
area: capture, recognition, results site, Cloudflare, failed reads, document profiles
paid-for-by: 2026-10-20, house session, step 4.1

The first recognition rule for the results site called a page a challenge
when "challenge-platform" appeared in it. 159 of 167 held files came out as
challenges, every real results page among them, because the site injects
the challenge script into the pages it serves normally. The block page is
known by `<title>Attention Required! | Cloudflare</title>` and its
`cf-error-details` block; a browser that failed before the page loaded is
known by the old job's `<!-- fetch error:` line. Measured with those: 156
read, 5 held and not read, 6 failed reads, none unrecognised. The same
script also changes a page's bytes at every capture, so a key built from
the hash would not survive a re-capture; key on the Commission's own
identities and cite the hash.
