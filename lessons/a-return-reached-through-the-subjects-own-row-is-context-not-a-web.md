A return or a declaration reached through the subject's own donation row is context, never a web to walk: expanding it lists every other donor in that return as if connected to the subject.
area: subject reports, products/report, the walk outward, templates
paid-for-by: 2026-10-20, report session, step 5.1

The first walk from a donor row treated the party return it sits on like a
company: it read the return's rows and listed the other 49 donors to New
Zealand First in 2023 as the subject's connections, each "confirmed" because
the return's key is an official number. They are not connections; they are
the same filing. The walk now expands a return, a candidate return, a
disclosure or an MP's return only when it is the start row
(`walk.EXPAND_ONLY_AS_START`); reached through the subject's row it is kept,
cited and shown as the record the donation sits in, and nothing is read
from it. A company is different: its directors and holders of record are
the register's own statement about who sits on it. The test that holds
this is `test_real.py::test_the_walk_from_a_known_donor…`, on the live
tables.
