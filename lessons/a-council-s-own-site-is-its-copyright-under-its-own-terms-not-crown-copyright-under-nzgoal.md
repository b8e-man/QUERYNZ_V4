Central agencies publish under NZGOAL, so a CC BY licence is the usual answer to question 2. Local authorities are
not bound by NZGOAL. Of 45 councils surveyed for their procurement pages, the three whose own sites list awards or
tenders each set their own terms: Clutha bars copying "for any commercial purpose", Tauranga allows non-commercial
use only, Dunedin offers use "upon request". The estate is built to be sold (ruling 2), so each is a bar or a
letter. Look first for the collected file (councils' GETS award notices are already held: 76 councils), then read
each council's terms page, land it by hash, and watch it, rather than assuming a public body's page is open data.
