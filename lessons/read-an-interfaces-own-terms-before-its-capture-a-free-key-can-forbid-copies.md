Read an interface's own terms before building its capture: a free key's terms can forbid permanent copies even where the material has no copyright.
area: capture, legal positions, registers/openlaw, any keyed interface
paid-for-by: 2026-10-21, openlaw-1, step 5.4 item 1

OpenLaw NZ's case law has no copyright (Copyright Act 1994, s 27(1)), and the
plan called its key "in hand and tested". The API terms that came with the key
(clause 3.6(a)) bar "scrape, build databases, or otherwise create permanent
copies" without OpenLaw's written authorisation. The old estate's notes
recorded the key and the schema but not the terms. Question 3 of the four
(what terms did we accept) is answered from the terms document, landed by
hash, not from the site's robots file or the material's copyright status.
Build the lane anyway, held behind a setting that names the missing
permission (here an `authorised:` line on the position page), so the
permission arriving is a one-line change and not a rewrite.
