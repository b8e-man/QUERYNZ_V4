Ruling 86 asked for a "source" link on every row that opens the captured
document. The rows look clean: the board's published views carry no home
address. But a party return or a candidate return prints each donor's
address beside the name. So does a disclosure. The Gazette prints a
bankrupt's, a tribunal order a tenant's, and the companies file a
director's residential address. A link that serves those bytes would show
on the board what no published table may hold.

The board now serves only the sources in `catalogue.SERVED_SOURCES`. Each
is there because every document it holds was measured: address-shaped lines
counted, and the context read with its digits masked, never printed. The
House lane had 167 documents and one such line (the Commission's own
authorisation); expenses had 103 and none. Every other held document says
"source held, not opened here" and answers 403 without its bytes being read.
Which further sources may open is in the decision queue with no default. A
redacted page image is the likely route.

Ruling 88 (26 October) settled it for the board alone: it is internal, on
the local network only, so it opens every captured document whole, the
addresses included, and `SERVED_SOURCES` is gone. The rule stands for every
other surface: the public site, the report, any export. A session still
never prints what such a document shows.
