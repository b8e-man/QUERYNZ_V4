A measure judged against another reading or a text layer counts layout and coverage differences as failures: a cell per line reads as a loop, a letterhead the layer lacks as invention. Bucket by size and look before the verdict.
area: reading documents, page readers, scoring, trials
paid-for-by: 2026-10-19, trial session, step 3.8

The trial's two failure measures (plan 3.7) take a reference: the page's
text layer where there is one, otherwise the other family's reading. Both
references are themselves readings with a layout and a coverage. On the
expense returns Infinity-Parser2-Pro writes every empty `$ 0.00` cell on
its own line and GLM-OCR writes the row on one line, so a table of ten
empty cells is "a line repeated ten times, where the reference shows
fewer": 14 of its 24 loop pages are under 20 repeats and are the table.
On the audited returns OvisOCR2 reads the auditor's letterhead and the
form's instruction box, which the text layer lacks and GLM-OCR skips; the
run is nowhere in either reference, so it is "invented". A real runaway
repeats a line 500 to 1,900 times and a real invention names a donor the
page does not carry; neither is what the counts were mostly made of.
Before a verdict, bucket every failure by its size and read a sample of
each bucket on pages that carry no person's details; a rule tuned on one
reader's layout is not a rule about the other reader. The counts stand in
the write-up with the buckets beside them.
