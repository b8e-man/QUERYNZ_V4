# Ruled operational defaults

KIND: doctrine (changes only by Arthur's ruling — created by ruling 148,
2026-09-01). One greppable table of operational defaults that carry a
ruling. Purpose: a fired operation that omits a ruled default is a
DEVIATION, and deviations must be decisions, not accidents — era_cutover's
preflight checks the machine block below and requires
`--accept-deviation <name>` to proceed past a missing one. (The specimen
this exists for: era 5 fired without `V3_SHARE_MINT=1` and single-box,
both against the B5 verdict, and nothing flagged it.)

## Machine block (read by era_cutover preflight)

Era-wave env defaults — `name = KEY=value` per line. The preflight compares
each line against the manifest env; a missing/different value halts the
plan/fire with the deviation named, unless `--accept-deviation <name>` is
passed (which records the acceptance in the manifest).

```ruled-era-env
share-mint = V3_SHARE_MINT=1
```

Non-env defaults (both-box-fleet, the lock rule, the metric) are enforced
by their own instruments: the per-box throughput gate, the consume test
battery, and the era harness — listed here so the map is complete.
