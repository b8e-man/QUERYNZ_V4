# Expense releases published as PDF are not held
kind: finding
state: open
use-case: 1
session: interests-expenses
opened: 2026-10-20

Both publishers release each quarter as a PDF as well as a workbook, and
for some quarters as a PDF alone. The old jobs captured workbooks only.
Internal Affairs' two listing pages (held) link 91 PDFs; the catalogue's
package lists 40 PDF and 42 HTML resources. Four of its resource names
carry no workbook; two of those quarters are held under another name (July
to September 2019; October to December 2017, in the workbook the catalogue
names January to March 2017, whose own title wins). October to December
2016 has no workbook, and January to March 2017 has none once that label
is set aside. Which ministers' quarters exist only as PDF has not been
measured; the listing pages carry the links.

Not fetched. A PDF release would need its own profile and reader (a
table on a page) and, for any scan, the page reader. Worth doing only for
quarters with no workbook; the measurement is the first step.
Blocks: nothing.
