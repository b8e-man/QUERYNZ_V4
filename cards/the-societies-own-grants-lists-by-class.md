# The class 4 societies' own grants lists, by class
kind: finding
state: open
use-case: 9, 14; step 6.3
session: grants-1, grants-2
opened: 2026-10-21

The Department's national file carries every society's grants for 2021 to 2025 and is read. Each society's own
list (Gambling Act 2003 s 110(4)) is the only source for 2017 to 2020 (ruling 71's window) and for the purpose as
printed. Survey: `registers/grants/survey.md`.

- **A. Lists as files: read in part (grants-2, 22 October 2026).** Eleven layouts from six societies read and
  checked (15,524 decisions): Air Rescue July 2017 to June 2026, Pelorus, Aotearoa Gaming Trust 2026, Trust Aoraki
  2025, Milestone November 2017 to March 2020, New Horizon, We Care 2022. Still to profile, each carded by hash in
  `registers/grants/unprofiled.list` (114 files): Milestone 2020 to 2026 (several layouts, the purpose printed; the
  2024 on lists carry a contact person's name in an "Applicant" column that must never be read); Trust Aoraki's A3
  sheets 2016 to 2022 (two or three blocks side by side under venue headings) and its 2024 to 2025 one-month
  posters; We Care's declined lists and its 2023 to 2025 annual reports. Not reached: NZ Community Trust's one list
  redirects to `static1.squarespace.com`, a host shared by every Squarespace site and named in no position (a
  position decision, not a code change); One Foundation's lists are built by script (move it to class C).
- **Differences found:** We Care's 2022 lists print 52 grants, $1,387,532; the national file has 55, $1,669,449
  (check.py reports it as known). Pelorus's declined list for 28 April 2026 is not published: its link serves the
  approved list again. Milestone's February 2019 file is titled February 2018. Seven files are scans (no page
  reader runs in this lane).
- **Terms:** the walk found a privacy page on the grants pages of Air Rescue, NZ Community Trust and New Horizon
  only, and landed it; none speaks to copying the lists. New Horizon's footer reads "All Rights Reserved", a plain
  copyright line like First Light's. No society's terms page was found, so none was read; the position's question 2
  (facts read and cited, words quoted) stands for a lawyer, society by society.
- **B. Grants pages, no list among the first three (12):** the whole-site walk from the grants page finds the list
  or shows there is none.
- **C. No grants link on the home page (6), and One Foundation:** likely script-built or a portal; a walk, then a
  headed browser that is shown no challenge.
- **D. Dead address on the Department's list (2):** Four Winds and Manukau Counties (`fourwindsfoundation.co.nz/MCCFCT`).
- **E. Another host (2):** Youthtown's `youthtowntrust.org.nz` is named in no position yet.
