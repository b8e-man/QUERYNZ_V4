# The class 4 societies' own grants lists, by class
kind: finding
state: open
use-case: 9, 14; step 6.3
session: grants-1
opened: 2026-10-21

The Department's national file carries every society's grants for 2021 to 2025 and is read. Each society's own
list (Gambling Act 2003 s 110(4)) is the only source for 2017 to 2020 (ruling 71's window) and for the purpose as
printed. Surveyed 21 October 2026 (`registers/grants/survey.md`), not read. By class, what each needs:

- **A. Lists as files (9 societies):** NZ Community Trust, Air Rescue Services, Pelorus, Aotearoa Gaming Trust, One
  Foundation, Trust Aoraki, New Horizon, Milestone, We Care. PDFs with a text layer (Air Rescue's are Excel
  exports: organisation, amounts requested and approved, declined reason code, territorial authority). One profile
  per society's layout, recognised by shape; the walk from each grants page lands the files; a capture list
  `society-file` and a society publisher key on each row (the society is then both publisher and grantor).
  Check against the national file where both cover 2021 to 2025: the same society's count and sum by year.
- **B. Grants pages, no list among the first three (12):** the whole-site walk from the grants page finds the list
  or shows there is none.
- **C. No grants link on the home page (6):** likely script-built or a portal; a walk, then a headed browser that is
  shown no challenge.
- **D. Dead address on the Department's list (2):** Four Winds and Manukau Counties (`fourwindsfoundation.co.nz/MCCFCT`).
- **E. Another host (2):** Youthtown's `youthtowntrust.org.nz` is named in no position yet.

Each society's terms are read before its first list; terms that forbid copies put that society behind one setting
and in the decision queue, marked no default.
