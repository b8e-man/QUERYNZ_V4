# A disclosure counts only in a year no return covers
kind: finding
state: accepted
use-case: 1
session: comparison
opened: 2026-10-20
closed: 2026-10-20

The rebuilt donor page counts a large declaration in a year's total only
when no annual return covers that year, and sights it otherwise (ruling
193: never summed into a return). The frozen donor page counted
declarations into the year's figure on its own rule, so a donor's year
with a declaration differs while the return rows agree: Aotearoa Te Kahu
Limited Partnership's 2021 ($120,000, Te Pāti Māori's 2021 return not
held, so the year is open on the rebuilt side) and seven others today.

Which side is right: neither is wrong; the rebuilt rule is ruling 193's.
Owner: site.
