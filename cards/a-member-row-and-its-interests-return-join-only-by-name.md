# A member's seat and the member's interests return join only by a name-only near link
kind: finding
state: open
use-case: subject report (5.1); 8 recruitment board screen
session: report
opened: 2026-10-20

The report now lists an interests return's declarations when the return is
the start or in the subject's own group. From a seat (`pub.members`,
`house:ge-2023/seat/…`) the return (`pub.mp_interest_returns`) is reached
only by `name-only@1`, graded near (603 such links; no confirmed rule joins
the two), so a screen started from a seat shows the declarations as a
namesake's. Both rows carry the member's name, party and electorate as the
House prints them, and `pub.names` marks both `politician`. For links: a
rule that joins a member row and an interests return on name, electorate
or list, and a return date inside the seat's term, confirmed; then the
report's walk needs nothing more (the return becomes a group row and is
expanded as the subject's own). Found closing
`an-mps-declared-interests-are-not-walked-from-a-person-start`.
