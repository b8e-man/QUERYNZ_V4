# How long a regulator's published action naming an individual is shown
default: While the regulator itself shows it: an entry the Commerce Commission, the FMA or WorkSafe takes down leaves our views at the next load
blocks: Nothing now; the products that show regulator actions (templates 5, 6, 7, the report shape) before anything is sold
recommendation: The default. It follows the publisher's own judgment (the Commission names an individual only in narrow cases, WorkSafe publishes a code where it withholds), needs no rule of ours, and is one place to change (each lane's load reads only the newest pass of the listing). A fixed window, like the Board decisions' three years (Building Act s 299), has no statute behind it here; open Commission investigations naming a person are the case to watch, and are shown as investigations, never findings
