`docs/plan/design.md` ("The Follow the Money template's own settings")
says calendar 2017 onward whole (ruling 364, 17 October; 366: 2017 is
no race), and that where the plan and the frozen site differ the frozen
site wins. The frozen site's home file at the freeze stands at

`settings.window_from` is 2017 and the figures compare with the frozen
site; the window is one number in `products/templates/ftm/ftm.json` and
moves by editing it. Recommendation: keep 2017, which is what the
comparison in 4.5 needs; rule 2019 only if 347 is meant to override 364.
