Subject: GETS award notices open data: automated access and the Supplier NZBN column

Kia ora,

I run Follow the Money (followthemoney.nz), a New Zealand public-records
service that links registers and cites every statement to its source. We
use your Government procurement award notices open data (CC BY 3.0 NZ,
attributed to MBIE) and would like to refresh it each quarter as you
publish it.

Two requests:

1. The files under www.mbie.govt.nz/assets/Data-Files/NZGPP-GETS-Open-Data/
   answer HTTP 403 to our reader, which identifies itself honestly as
   "QueryNZ/1.0 (research aggregator; contact: admin@followthemoney.nz)"
   and asks for each file once, at least ten seconds apart. Could that
   User-Agent be allowed, or is there another address for the files that
   automated readers may use?

2. In the supplier file the "Supplier NZBN" column reaches us without its
   digits: most values are in spreadsheet exponent form (for example
   9.42904E+12), and none is a complete 13-digit NZBN. Could the column be
   exported as text, so the numbers survive?

Ngā mihi,
Arthur
