# registers/building_practitioners — licensed building practitioners

Step 5.3 (for use cases 6, 7 and 12). The public register under part 4 of
the Building Act 2004: one row per licensed practitioner (licence number,
name as published, licence classes with dates, status, the area the
register publishes and nothing finer) and one row per published
disciplinary decision. No address is read.

Built by `sanctions-1`, with `registers/sanctions/` and
`registers/limited_partnerships/`.
