# Incorporated societies, on the board

One pane per society, from `pub.societies`: its name, NZBN and
incorporation number, status, the Act it is registered under, its
registration and removal dates, and, from `pub.society_states`, any earlier
name or status the monthly file changed. Then its officers, from
`pub.society_officers`: current first (status Active), then past, each with
the register's own start and end, and "read on" as the first and last days
an ask listed it. A role the register stopped listing keeps its last day
read; it is never given an end the register did not state. A suppressed
name shows as "name suppressed"; the row stays. No address is shown.

A person pane lists every society role a name holds, each cited to the
document it came from (an export line, or one ask's answer) and the day read.
The party societies (the old product's shape: Labour, Green, Te Pāti Māori,
the Māori Party, Opportunity) are marked and asked every night.

The lane's own line on the board: the outside check, the last
`qv4-societies-capture` run (asked, landed, failed, where it stopped) and the
catch log's count.
