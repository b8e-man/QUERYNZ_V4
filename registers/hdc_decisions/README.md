# registers/hdc_decisions — Health and Disability Commissioner decisions

Step 5.3, a source to acquire (for use case 11, healthcare operator
governance). The Commissioner's published decisions and case studies from
2017 (ruling 71), captured verbatim by hash through the fetch gate under
the four questions, read by profile into one row per decision (file number,
date, the kind of decision, the provider kinds, the Code rights tagged and
stated as breached, findings per party, the recommendations' headings and
addressees, the page's address) and one row per provider organisation the
Commissioner names. A consumer, a family member or anyone the Commissioner
anonymises is never named or described; an individual practitioner the
Commissioner names is kept as a role and the naming policy's ground.

**Held** on the Commissioner's copyright terms (3.2: written permission for
any use beyond research): the capture into the estate, the load job and the
views refuse until `position/hdc-decisions.md` carries an `authorised:`
line. Built by `hdc-1` and proved on real pages in the sample database.
