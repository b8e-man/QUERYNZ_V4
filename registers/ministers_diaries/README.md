# registers/ministers_diaries — ministers' diaries, as proactively released

Step 6.2, template 4(a) (use case 15; Arthur, 17 October). A built register:
the monthly diary release each minister publishes on the Beehive (a PDF),
one row per meeting as released, from the MCP's `parliament-diaries`
corpus (rulings 78, 96): the provider read the PDFs off-estate. Names as
printed and linked to nobody (product (b) comes after links); the release's
withholdings kept and counted; the meeting, attendees and location whole, flagged where the shape names a home or an address (ruling 102).
Ministers only: backbench MPs publish no diary. Built by `diaries-2`.
