# registers/ministers_diaries — ministers' diaries, as proactively released

Step 6.2, template 4(a) (use case 15; Arthur, 17 October: the first of
the four lobbying products, with no dependency). A built register: the
monthly diary releases each minister publishes as a proactive release,
captured verbatim by hash through the fetch gate (ruling 242: a
government's proactive release is collectable, politely), read by a
profile per diary layout into one row per diary entry (minister,
portfolio, date, the meeting or event as released, who attended as
released), with the release's own redactions kept as redactions. Ministers
only: backbench MPs publish no diary.

Built by `diaries-1`; `spec.md`, `capture.py`, `read.py`, `load.py`,
`publish.sql`, `check.py`, `sample.list`, `tests/` and the position page
are its deliverable.
