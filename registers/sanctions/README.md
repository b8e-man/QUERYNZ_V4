# registers/sanctions — the sanctions lists New Zealand law applies

Step 5.3 (for use case 13). The Ministry of Foreign Affairs and Trade's
register under the Russia Sanctions Act 2022, the United Nations Security
Council consolidated list, and the Police list of designated terrorist
entities, each captured verbatim by hash as its publisher issues it and read
into one row per listing with the list's own identifiers, names and
aliases, the designation's date and basis.

Built by `sanctions-1`, with `registers/limited_partnerships/` and
`registers/building_practitioners/`.
