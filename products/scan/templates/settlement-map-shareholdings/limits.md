# settlement-map-shareholdings: known limits and the checkpoint

Template 3, each shareholding the companies register files under the
body's name, and the company it is in. The six scans, the shared limits
and the ten bodies read by eye are on `../settlement-map-iwi/limits.md`.
For the register scan only, never for the public site.

## Known limits

- **By name alone, near.** The holder's NZBN is never printed by the
  directory, so the holder's filed name is folded and compared.
- **A holding is not a body:** several holdings under one name are not
  namesakes and are not marked so (lesson
  `a-namesake-count-means-something-only-where-each-row-is-one-body`).
- **A suppressed holder is never compared** (`where suppressed = false`,
  a rule the tests hold on every template).
- **As filed:** shares and allocation as the register files them, the
  holder type the register's own (41 holdings typed "individual" under a
  body's name, trustees holding for a trust). Nothing is added up or
  followed further. The trustee flag marks a company named "… Trustee …".
